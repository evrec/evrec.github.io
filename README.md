# Atlante di anatomia 3D

A free, open-source 3D atlas of the human musculoskeletal system for anatomy students. Every bone with its named landmarks, every muscle with its individual heads, each with a short study card. The interface and cards are in Italian.

Covers head, neck, trunk, upper limb and lower limb: 369 structures and 522 bony landmarks.

## Run locally

```bash
python -m http.server 8765 --directory docs
```

Then open `http://localhost:8765`. The site is static, with no build step.

## Available At: https://evrec.github.io/

## Layout

- `docs/`: the site served by GitHub Pages, i.e. the viewer (`index.html`, `app.js`, three.js from a CDN).
- `docs/data/`: models and structure trees, generated by `tools/export_region.py` from the Z-Anatomy Blender file. Do not edit by hand.
- `docs/content/`: hand-written cards. `tools/check_content.py` validates them.

## Sources and review status

Card texts are original. Classification and nomenclature follow the Italian anatomical tradition; textbooks were used only as a reference for facts, and no text or figure was copied. The cards have **not yet been reviewed by an anatomy teacher**: corrections are welcome.
